# Hnswlib for NodeRAG
Header-only C++ HNSW implementation with python bindings, insertions and updates.

This updated version introduces new bindings for the graph layer visualization in the original [hnswlib project](https://github.com/nmslib/hnswlib). If you are interested in HNSW, please refer to the original GitHub repository. This project is just for specific project (NodeRAG use).
